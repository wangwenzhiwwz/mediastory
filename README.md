# MediaStory

短视频与影视广告分镜制作工作台。

## 主要特性

- **分镜表格**：支持自定义列排版、列宽无级调节、列显隐与列重命名。
- **拖拽排序**：支持顺畅拖拽调整镜头顺序并自动刷新镜号。
- **排版导出**：支持导出与预览一致的 A4 横向 PDF 与 Excel 文件。
- **图片录入**：支持点击上传、拖拽放入以及从剪贴板粘贴图片。
- **团队口令**：支持基于团队访问口令的轻量化权限管理。

## 本地运行

1. 安装依赖：
   ```bash
   npm install
   ```
2. 启动开发服务：
   ```bash
   npm run dev
   ```
3. 访问 `http://localhost:676` 并输入口令即可使用。

## Docker 部署

使用 Docker Compose 快速运行：

```bash
docker compose up -d --build
```

数据持久化保存在 Docker 卷中。
