## Reference

Seven supplied desktop screenshots covering the project library, storyboard table,
storyboard cards, shooting plan, call sheet, and export preview.

## Comparison

- Project library reproduces the narrow icon rail, sparse folder grid, search and
  compact project metadata.
- Project workspace reproduces the persistent top process navigation and right-side
  collaboration/export controls.
- Storyboard editing uses the reference's dense row/table structure with inline
  editing, image replacement, insert controls and alternating rows.
- Storyboard preview uses the reference's image-led card grid and metadata chips.
- Shooting plan uses scene-grouped columns with selectable shot rows.
- Export preview uses the reference's fixed settings rail and printable page canvas.
- Typography, pale gray surfaces, yellow primary actions, thin borders, compact
  controls, and rounded white cards are visually aligned with the references.
